# Releasing Gear4J

## CI provider

Gear4J uses GitHub Actions.

The release workflow is `.github/workflows/release.yml`.

## Maven Central namespace

The configured Maven group is:

```text
io.github.gear4jtest
```

Before the first release, this namespace must be registered and verified in the Central Publisher Portal.

## Required GitHub secrets

Configure these repository secrets:

```text
JRELEASER_GPG_PUBLIC_KEY
JRELEASER_GPG_SECRET_KEY
JRELEASER_GPG_PASSPHRASE
MAVEN_CENTRAL_USERNAME
MAVEN_CENTRAL_PASSWORD
```

`MAVEN_CENTRAL_USERNAME` and `MAVEN_CENTRAL_PASSWORD` are the username/password values generated by a Central Portal user token.

## Local dry run

```bash
./gradlew clean releaseCheck stageMavenCentral -PprojectVersion=1.0.0
JRELEASER_DRY_RUN=true ./gradlew jreleaserDeploy -PprojectVersion=1.0.0
```

## GitHub release

Create and push a version tag:

```bash
git tag v1.0.0
git push origin v1.0.0
```

The release workflow will:

1. run checks;
2. run integration tests;
3. run dependency vulnerability scan;
4. stage Maven artifacts under `build/staging-deploy`;
5. sign and deploy staged artifacts with JReleaser.

Manual dispatch is also available. It defaults to dry-run mode.
